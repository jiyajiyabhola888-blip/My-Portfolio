# Jiya Bhola — Monochrome Developer Portfolio

## Run locally
1. Open this folder in VS Code.
2. Make sure `assets/images/profile/jiyaprofile.jpg` is present.
3. Open `index.html` with Live Server, or simply double-click it.
4. Move the mouse over the portrait: the gaze follows the pointer.

## Main files
- `index.html` — content and sections
- `style.css` — monochrome visual system, responsive layout and animations
- `script.js` — cursor follower, magnetic interactions, portrait gaze and scroll reveal
- `assets/images/profile/jiyaprofile.jpg` — supplied professional portrait

## Featured projects
- YourSafePlace
- GitOut
- AI Resume Analyzer
- AI Virtual Mouse
- Nimbus Notes

Replace the placeholder email in `index.html` with the real professional email before publishing.

## Deploy
This is a static site and can be deployed with GitHub Pages, Netlify, Vercel or similar static hosting.
